# Daily List (PWA)

แอป To-do รายวันแบบติดตั้งลงมือถือได้ ใช้งานได้แม้ไม่มีเน็ต

## ไฟล์ในโฟลเดอร์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอป (หน้าจอ + โค้ดทั้งหมด) |
| `manifest.webmanifest` | ชื่อแอป ไอคอน สี ใช้ตอนติดตั้ง |
| `sw.js` | Service Worker เก็บแอปไว้ในเครื่อง ให้เปิดได้ตอนออฟไลน์ |
| `icons/` | ไอคอนแอป 192 px, 512 px และแบบ maskable ของ Android |

## นำขึ้น GitHub Pages (ฟรี)

1. สมัคร/ล็อกอิน https://github.com
2. กด **New repository** ตั้งชื่อ `daily-list` เลือก **Public** แล้วกด Create
3. กด **uploading an existing file** ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ `icons`) ลงไป แล้วกด **Commit changes**
4. ไปที่ **Settings → Pages** ตรง Branch เลือก `main` / `(root)` แล้วกด Save
5. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/daily-list/`

## ติดตั้งบน Android

1. เปิดลิงก์ด้านบนใน **Chrome**
2. กดปุ่ม **ติดตั้งแอป** ที่เด้งขึ้นมา หรือเมนู ⋮ → **ติดตั้งแอป** (Install app)
3. ไอคอน Daily List จะอยู่บนหน้าจอและในลิ้นชักแอป

## อัปเดตแอป

แก้ไฟล์แล้วอัปโหลดทับใน GitHub และเปลี่ยนเลข `VERSION` ใน `sw.js` ทุกครั้ง
แอปในมือถือจะได้เวอร์ชันใหม่เมื่อเปิดตอนมีเน็ต (บางครั้งต้องปิด-เปิดแอป 2 รอบ)
